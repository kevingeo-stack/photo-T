# system_map.md# Architecture & System Map## 1. Firebase Structure### Cloud Storage- `/users/{userId}/uploads/{filename}` (Raw image files)### Firestore (Strict Even-Segment Paths)- Collection: `users`  - Document: `{userId}`    - Collection: `images`      - Document: `{imageId}`        - Fields: `url`, `filename`, `status` (kept/discarded/pending), `uploadedAt`, `size`, `format`## 2. OOP Class Hierarchy (Frontend)- `AppController` (Entry point, initializes services)- **Services (Data Layer):**  - `FirebaseService` (Auth, Firestore init, strict path validations)  - `StorageService` (Cloud Storage uploads/downloads)  - `OfflineStorageService` (IndexedDB management for PWA caching)- **Managers (Business Logic):**  - `PhotoManager` (State management, handles upload queues, triage logic)  - `ComparisonManager` (Logic for side-by-side comparison state)- **UI Controllers (Presentation Layer):**  - `GalleryUI` (Renders grid, drag-and-drop events)  - `ComparisonUI` (Renders side-by-side view, zoom/pan events)  - `ThemeManager` (Imports and applies Stitch CSS/Theme)## 3. PWA Structure- `/index.html` (App shell)- `/manifest.json` (PWA specs)- `/sw.js` (Service Worker for network-first/cache-first strategies)- `/assets/` (Icons and Stitch CSS)
